    Implementation ≠ release verification

    Status reflects a source implementation review. Every flow must still be exercised on real devices with its backend, account state, payment provider, and push configuration.

    How to read this map

    Solid emerald is implemented UI, dashed amber depends on runtime services, violet marks a role guard, and red marks a blocked or unverified connection. Each node shows its incoming and outgoing link count.

    Not live analytics

    This is a product map and build-progress preview. Counts and statuses describe the code inventory, not user activity, uptime, or production behavior.
